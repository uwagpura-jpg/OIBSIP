# Python Voice Assistant

## About

This is a beginner-friendly Python command-line assistant that responds to user commands and performs simple tasks.

## Features

* Greets the user
* Displays the current time and date
* Performs basic calculations
* Displays available commands
* Handles invalid commands and invalid number inputs
* Exits when the user types `exit`

## Technologies Used

* Python 3
* `datetime` module

## How to Run

1. Open the terminal in this project folder.

2. Run the following command:

   `python3 voice_assistant.py`

3. Type `help` to see the available commands.

## Sample Commands

* `hello`
* `time`
* `date`
* `calc`
* `help`
* `exit`
