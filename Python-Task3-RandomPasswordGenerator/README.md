
# Random Password Generator

A command-line Random Password Generator built using Python for the Oasis Infobyte Python Programming Internship (OIBSIP).

## Features
- Generates passwords with a minimum length of 8 characters.
- Supports lowercase letters, uppercase letters, numbers, and symbols.
- Requires at least two character types.
- Ensures every selected character type appears at least once.
- Handles invalid length and character-type choices.
- Uses Python's secrets module for secure random selection.
- Allows users to generate multiple passwords.

## Technologies Used
- Python 3
- string module
- secrets module

## How to Run

Run the following command in the project directory:

```bash
python3 password_generator.py
```
