# Basic Weather App

## About

This project is a beginner-level Python application designed to fetch and display current weather information for a user-specified city using a weather API.

## Features

* Accepts a city name from the user
* Uses an API request to retrieve weather data
* Parses JSON weather responses
* Designed to display current weather information

## Technologies Used

* Python 3
* Requests library
* JSON
* OpenWeatherMap API

## How to Run

1. Install the required library:

   `pip install requests`

2. Run the application:

   `python3 weather_app.py`

3. Enter a city name when prompted.

## Project Structure

* `weather_app.py` — Main Python program
* `README.md` — Project documentation

## Notes

A valid weather API key and an internet connection may be required. API errors can prevent weather data from being retrieved.
